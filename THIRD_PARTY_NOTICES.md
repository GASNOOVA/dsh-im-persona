## 微信 iLink 协议适配

The Weixin iLink request format, QR-login states, and message fields are adapted from Tencent's [`openclaw-weixin`](https://github.com/Tencent/openclaw-weixin) project at commit `cef0bfc390393f716903e16d50408118047f87e0` (package version 2.4.6), licensed under the MIT License and copyright Tencent.

## QQ 机器人

QQ QR binding uses Tencent Connect's official [`@tencent-connect/qqbot-connector`](https://www.npmjs.com/package/@tencent-connect/qqbot-connector) 1.2.0 package as an external runtime dependency. Its npm metadata declares `UNLICENSED`; no connector source is copied into this project.

QQ messaging and command handling depend at runtime on Tencent Connect's [`@tencent-connect/qqbot-nodejs`](https://github.com/tencent-connect/qqbot) 1.0.4, licensed under the MIT License; it is installed separately and not bundled.

## 内置人设「大肥鱼」

内置人设「大肥鱼」的角色设定正文整合自 [`dsh-persona-dafeiyu`](https://github.com/huaizhuanghub/dsh-persona-dafeiyu)（`BUNDLED_DAFEIYU` 常量），该项目以 MIT License 发布，Copyright (c) 2026 dsh-persona-dafeiyu contributors。正文按原样收录于本仓库 `src/channels/shared/persona-presets.mjs`；本仓库未复制该项目的其余代码。

## 其它运行时依赖

[`sharp`](https://github.com/lovell/sharp) 0.35.5 is an optional dependency (Apache-2.0) used for local image preprocessing when available; it is installed separately and not bundled.
