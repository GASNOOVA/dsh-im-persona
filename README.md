# dsh-im-persona · 个人定制版 IM 机器人

> 把 **微信** 和 **QQ** 接入 [DeepSeek Harness](https://github.com/deepseek-ai)，并支持为每个机器人配置**角色人设**。
>
> 本仓库是 [`@xmanrui/dsh-im`](https://github.com/xmanrui/dsh-im) v5.10.0 的独立个人定制版（MIT）：只保留实际使用的两个渠道，重做品牌与交互，新增人设能力。**不追上游、不做合并**。

---

## 1. 特性一览

- **两个渠道**：微信（扫码绑定，私聊）与 QQ（扫码或 AppID/AppSecret，私聊 + 群聊 @）。
- **每机器人人设**：角色名、性格语气、自定义提示词，注入到该机器人的每条普通用户消息；命令与审批不注入。
- **闲时启用（省 API 成本）**：全局开关，开启后只在 DeepSeek API 空闲时段响应消息；高峰时段（北京时间周一至周五 09:00–12:00、14:00–18:00，法定节假日除外）不调用模型、不建会话，只自动回复一条固定提示（不消耗 token）；周末与法定节假日全天按空闲时段（半价）。见 [闲时启用](docs/闲时启用.md)。
- **群聊大脑（实验性）**：面向小群（默认 ≤5 人）的主动参与——记录群聊、维护永久群记忆与成员画像，在一段讨论停顿后偶尔自然接一句话；被 @ 后还有「连续对话窗口」（默认 5 分钟、默认最多 8 条、可调至 100 条、最小间隔 3 秒、同一成员 30 秒内的连续消息合并为一次回复且窗口可调），窗口内未 @ 的群消息也会自然接话形成连续聊天；同群多人同时发言时会按成员排队逐一回复；同一个群的所有回复复用同一个 DSH 会话，上下文连贯；复用会话后只补新消息，不再每轮重复注入人设/记忆/画像（提示词最小化）；支持独立「大肥鱼（群聊版）」人设。QQ 群已可用；微信群聊可通过可选的 agent-wechat 个人号桥接接入（非官方协议，实验性）。见 [群聊大脑](docs/群聊大脑.md)。
- **多机器人独立管理**：同一渠道可接多个机器人，凭据、连接状态、工作区、模型、Agent Preset、会话绑定彼此独立。
- **完整任务闭环**：流式/分步呈现、图片与文件输入、结果文件回传、超时延迟交付、主动投递与会话同步。
- **安全与可控**：访问模式（开放/白名单）、命令权限、上下文增强（来源信息 + 引导词）、会话目录隔离。
- **QQ 群消息记录**：按群保存最近消息与群文件，@ 机器人即可查询、总结或读取。

## 2. 渠道能力

| 渠道 | 接入方式 | 消息与回复 |
| --- | --- | --- |
| **微信** | 使用微信扫码绑定机器人（iLink 长轮询） | 仅私聊；等待回答时显示「正在输入」，最终回复按 1,800 字符分段；支持图片/文件输入与结果文件回传；可用 `/plan`、`/goal` |
| **QQ** | 手机 QQ 扫码创建机器人，或 AppID + AppSecret 手动绑定（WebSocket 长连接） | 私聊直接回复、群聊被 @ 后回复；显示「正在输入」，私聊以单条 Markdown 回复；支持图片/文件输入与结果文件回传、`/menu` 可点击菜单 |
| **微信个人号（可选，群聊扩展）** | 本机运行 [agent-wechat](https://github.com/thisnick/agent-wechat) daemon，用小号扫码登录；需常驻进程 | 群聊被 @ 时回复、开启群聊大脑后可在小群主动接话；目前仅文本；非官方协议，有账号风控风险，建议专用小号 |

两个渠道都支持：每机器人工作区 / 模型 / 推理等级 / Agent Preset、上下文增强、访问模式、命令权限、主动投递、延迟交付、`/history`、批量输入等。

## 3. 安装

### 前置

- Node.js **>= 22.19**
- DeepSeek Harness **>= 0.2.1-rc.2**（开发验证基线：`0.2.2-rc.1`，Web profile）
- 本仓库已 `npm install` 并构建

### 从源码构建并安装

```sh
cd /mnt/volume/dsh/dsh-im-persona
npm install
npm run build            # 生成 lib/index.js（Host）与 lib/client.js（Web 客户端）

# 方式 A：本地链接安装（开发期推荐，改代码后重新 build 即可）
dsh plugin --profile web add -w link:/mnt/volume/dsh/dsh-im-persona

# 方式 B：个人版安装器
node bin/dsh-im-persona.mjs install --source .

# 方式 C：发布到 npm / GitHub 之后
dsh plugin --profile web add -w github:GASNOOVA/dsh-im-persona
```

安装后**重启 `dsh web`**，刷新浏览器，打开「设置 → **IM机器人（个人版）**」。

> 说明：`lib/` 不提交到仓库，必须构建后才可安装；打包和安装细节见 [改造方案 §7](docs/改造方案.md)。

### 卸载

```sh
dsh plugin --profile web remove dsh-im-persona
```

## 4. 使用

1. 左侧主界面默认出现 **「IM机器人」** 图标（个人版默认始终显示），点击进入 IM 面板；也可以在「设置 → IM机器人」打开同一页面。不需要时可在「通用设置 → 通用 → 侧边栏入口」改为自动或隐藏。
2. 面板里只显示 **微信**、**QQ** 两个渠道。
3. 点击对应渠道的「扫码接入」/「手动接入」创建机器人；扫码结果与凭据只保存在本机 Host。
4. 机器人卡片上可以：
   - 查看连接状态、检查连接、重试连接、移除接入；
   - 设置**工作区**（绝对路径或目录选择器）；
   - 选择**模型 / 推理等级 / Agent Preset**（只影响之后新建的会话）；
   - 打开**人设**页签（见第 5 节）；
   - 打开**更多设置**：投递设置、访问设置、上下文增强、群消息记录等。
5. 在微信/QQ 里给机器人发消息即可开始。

### 微信个人号群聊（可选，实验性）

官方微信（iLink 扫码机器人）无法进群，也收不到普通群事件。如果希望机器人在微信群里被 @ 回复、并由群聊大脑主动接话，可以额外接入 agent-wechat 个人号桥接：

1. 安装并启动本机 daemon（Node >= 24）：
   ```sh
   npm install -g @agent-wechat/cli
   wx accounts create xiaohao --alias xiaohao
   wx serve --listen 127.0.0.1:16174
   ```
2. 扫码登录专用小号：`wx auth login --strategy qr`，手机扫码并确认；`wx auth status` 显示 `authenticated: true`、`connection: online`。
3. 在插件里：设置 → **IM机器人** → **通用** → **群聊大脑** → **微信个人号（agent-wechat）**：
   - **启用**；
   - **daemon 地址**：默认 `http://127.0.0.1:16174`；
   - **账号 ID**：`xiaohao`（第 1 步创建的账号）；
   - **token 文件路径**：agent-wechat 数据目录下的 `api-token`（例如 `~/.local/share/agent-wechat/api-token`；本项目实测部署在 `/mnt/volume/dsh/.im/agent-wechat/aw-data/api-token`）；
   - **群聊人设**：默认「大肥鱼（群聊版）」；
   - 点击**测试 daemon 连接**确认登录态与可见会话。
4. 保存后群聊大脑会连接 daemon 的事件流；把机器人拉进小群后 @ 它即可回复。若希望未 @ 也自动接话，在「自动接话白名单」加入该群（格式 `wechat-personal:xiaohao:群ID:群名`），或依赖小群人数上限（agent-wechat 能提供成员数，≤5 人自动生效）。

## 5. 人设（Persona）

每个机器人可以选择一份人设，内置两条：**大肥鱼**（私聊版）与 **大肥鱼（群聊版）**（来自 [dsh-persona-dafeiyu](https://github.com/huaizhuanghub/dsh-persona-dafeiyu)，MIT；群聊版在此基础上追加群聊行为准则），也可以导入自己的人设：

- 打开机器人卡片 → **人设**：
  - **人设库**：选择内置大肥鱼 / 大肥鱼（群聊版）或已导入的人设，可「查看全文」；
  - **导入人设**：粘贴正文，或选择本地 `.md` / `.markdown` / `.txt` 文件（≤64,000 字符，名字 ≤60 字符），导入后可重命名、删除；
  - **自定义**：不选人设库时，可直接填写角色名、性格语气、补充要求（每机器人独立）；
  - 也可在插件 config 中用 `personaFile` 指定一个外部人设文件（只读，作为人设库的 `config` 条目）。
- 保存后**从下一条消息起生效**：人设注入到该机器人的每条普通用户消息（与上下文增强的来源块协同），不影响命令（`/...`）、审批回答与问题回答；
- 人设是机器人级配置：`/new` 之后仍然生效，已有会话的后续消息同样生效（历史不回溯）；群聊大脑自动接话时，选私聊版大肥鱼会额外叠加群聊准则，选群聊版则直接使用；
- 人设库与机器人选择都在 Host 侧持久化（`$DSH_HOME/integrations/dsh-im/`），重启 DSH 后保留。

用户指南见 [人设库](docs/人设库.md)，完整设计、注入格式与 RPC 见 [人设能力设计](docs/改造/02-人设能力.md)。

## 6. 常用命令

微信与 QQ 都支持（两者略有差异）：

| 命令 | 作用 |
| --- | --- |
| `/help` | 显示当前机器人支持的完整命令 |
| `/new [标题]` | 解除当前聊天绑定，下一条消息新建会话 |
| `/fork [标题]`、`/reset` | 从当前会话分支 / 重置上下文 |
| `/ls`、`/go N`、`/prev`、`/next`、`/drop N` | 本聊天会话列表与前后切换（微信/QQ 原生桥） |
| `/title`、`/tail` | 查看/重命名标题、预览最近消息 |
| `/workspace`、`/ws`、`/wsl` | 切换/列出工作区 |
| `/sessionlist`、`/session` | 列出会话、绑定指定会话 |
| `/models`、`/model`、`/reasoninglist`、`/reasoning` | 查看/切换模型与推理等级 |
| `/presetlist`、`/preset` | 查看/设置机器人 Agent Preset |
| `/compact`、`/clear` | 压缩上下文 / 清空上下文（保留绑定） |
| `/stop`、`/steer` | 停止当前任务 / 纠偏 |
| `/batch`、`/send`、`/cancel` | 批量输入（仅私聊，最多 10 条） |
| `/status`、`/version` | 连接状态、插件版本 |
| `/history [N]` | 查看最近历史（默认 3 条，最多 5 条） |
| `/plan`、`/goal` | 计划模式、目标管理（微信） |
| `/permissionlist`、`/permission` | 查看/切换会话权限（QQ） |
| `/menu` | 打开可点击功能菜单（QQ） |

## 7. 其它能力

- **上下文增强**：为群聊/私聊分别配置来源字段与增强提示词，作为用户消息内容注入，不修改系统提示词。见 [上下文增强](docs/上下文增强.md)。
- **闲时启用**：开启后仅 DeepSeek 空闲时段响应（周末、法定节假日全天空闲，工作日高峰以外半价），高峰时段不调用模型、只回一条固定提示以节省 API 费用；内置 2026/2027 节假日表，可用「同步节假日」按钮从 holiday-cn 更新。见 [闲时启用](docs/闲时启用.md)。
- **群聊大脑**：小群主动接话、被 @ 后的连续对话窗口、永久群记忆、30 天记忆整理、成员画像；支持 QQ 群与微信个人号群聊；设置页可配置白名单、接话节奏、连续对话窗口与微信个人号连接。见 [群聊大脑](docs/群聊大脑.md)。
- **访问模式**：按渠道选择「开放」或「白名单」，并单独控制命令权限。见 [访问模式](docs/访问模式.md)。
- **主动投递与会话同步**：用稳定的 `botId + targetId` 主动发消息、把会话结果同步回聊天；HTTP/RPC 均可调用。见 [主动投递使用指南](PROACTIVE_DELIVERY.md)。
- **延迟交付**：前台超时后继续监视同一回合，完成后补发结果。见 [延迟交付](docs/deferred-delivery.md)。
- **QQ 群消息记录**：按群滚动保存最近 14 天消息与附件，@ 机器人即可查询/总结/读取文件。见 [群消息记录](docs/group-history.md)。
- **群聊大脑**：未 @ 消息也进入群记忆与话题判断；讨论停顿时可按节奏接话，默认每 30 天压缩为长期记忆与成员画像。见 [群聊大脑](docs/群聊大脑.md)。
- **群聊版人设**：内置「大肥鱼（群聊版）」独立人设，与私聊版分开；选中私聊版时群聊回复会自动叠加群聊行为准则。
- **会话目录隔离**：为不同会话自动建立独立目录。见 [会话目录隔离](docs/会话目录隔离.md)。
- **Agent Preset 分组**：选择 Preset 后按 Preset 建立工作区分组。见 [preset-workspaces](docs/preset-workspaces.md)。
- **界面语言**：设置页与机器人消息跟随 DSH 语言（中文/English/Русский），中文兜底。

## 10. 已知限制

- 官方微信（iLink 扫码）仅私聊；微信群聊需可选的 agent-wechat 个人号桥接（非官方协议，需常驻 daemon，仅有文本能力，账号存在风控风险，建议专用小号）；
- QQ 群聊默认仅在被 @ 或回复机器人消息时响应；微信个人号群聊需 @ 元数据；开启群聊大脑并配置白名单（或小群 ≤5 人）后，未 @ 消息也会进入记忆并可能触发自动接话；
- 人设属于用户消息内容，模型**可能**不完全遵守，重要场景请在提示词中写明硬性约束；
- 个人版移除了「检查并安装更新」：升级方式为 `git pull && npm install && npm run build` 后重启 DSH；
- 未恢复 CI，未引入上游桌面端侧栏接入（`integrations/desktop-panel`）；
- 闲时启用的时段固定为 DeepSeek 官方优惠时段，不支持自定义；高峰期会回一条固定提示（同一聊天 5 分钟最多一次），消息不进入会话、不补发，且不影响进行中的任务与计划任务。
