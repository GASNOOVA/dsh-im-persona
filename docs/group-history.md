# 群聊天记录（Group history）

DSH-IM 可以自动保存实际收到的 QQ 群消息及附件。之后在该群内 @ 机器人，即可查询聊天记录、总结讨论或读取文件。

> 个人版只保留微信（weixin）与 QQ（qq）两个渠道，群记录能力**仅 QQ 适用**：微信渠道不支持群聊。

## 能力与限制

- 记录按群共享，独立于机器人、AI 会话和工作区。同一 DSH 数据目录内、同一群身份下的机器人可读取同一份记录；切换会话、工作区或删除某个机器人不会删除群记录。
- 只保存平台实际投递的消息。QQ 记录目前按应用来源隔离，不支持不同 QQ 应用之间自动共享同一实体群的记录。
- 不完整同步编辑、撤回和机器人之间的消息；媒体文件是否可读取决于平台消息事件中是否携带可下载附件。
- 只保存最近若干天（默认 14 天，可在群记录设置中调整）的记录；这是本地归档，不是完整的平台聊天备份。

## 接入 QQ 群

1. 扫码新增或使用 AppID + AppSecret 接入 QQ 机器人，并将其加入目标群。
2. 由群主按 QQ 对该机器人提供的授权入口，允许其查看群内全部对话。入口是否提供取决于 QQ 应用能力和客户端，不能仅凭“机器人已入群”判断已授权。
3. 在机器人卡片或群记录设置中调整保留天数与开关；默认关闭归档，开启后只对新收到的消息生效。

应用需要具备接收普通群消息的能力；实际是否投递以应用能力与群授权为准，参见[腾讯官方 SDK](https://github.com/tencent-connect/qqbot-nodejs)。若 QQ 没有向当前应用开放普通群消息，本插件无法通过本地设置补齐平台未投递的数据。

## 查询方式

在群里 @ 机器人后正常提问即可，例如：

- “总结一下今天的聊天”
- “刚才谁提到了部署？”
- “把张三发的那份文件内容读一下”

机器人通过内置的群记录工具读取最近消息与附件，只有实际收到且已归档的内容可被检索。图片与文件以本地归档副本为准，外部链接或未投递的消息不会出现。

## 存储与清理

群记录保存在 DSH home 下的本地数据目录中（与各机器人状态分开），按群隔离。修改保留天数后，超期记录在后续写入或清理时移除；删除 DSH 数据目录会同时删除群记录。
