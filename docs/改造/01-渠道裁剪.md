## 4. Host i18n 回收说明（重要）

上游把不少**仍被微信/QQ/共享代码使用**的中文文案放在被删渠道的词典文件里（例如 `上一页`、`已请求停止后台任务。`、`结果文件已生成。`、`二维码已过期，请重新生成。` 在 `feishu/wecom/dingtalk` 词典中）。如果直接删词典，`i18n-coverage` 单测会报“untranslated source strings”。处理方式：

1. 从基线 `git show HEAD:src/channels/shared/i18n-<lang>/<removed>.mjs` 提取仍被当前源码引用的条目（EN/RU 各 83 条），写入新增的 `src/channels/shared/i18n-<lang>/legacy-shared.mjs` 并在聚合器合并；含移除渠道品牌名的条目直接丢弃。
2. 其余渠道词典（品牌化条目）删除。
3. `shared-d.mjs` 删除因 `text-harness-bridge` 删除而不再被引用的 16 个键；`/ls` 帮助行改为新表述并补 en/ru 译文。
4. 结果：`node --test test/channels/shared/i18n-coverage.test.mjs` **全部通过**；`src`/`plugin-src` 中已无被移除渠道标识符（注释除外）。
