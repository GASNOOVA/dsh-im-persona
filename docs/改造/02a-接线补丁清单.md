## 1. 命名契约（全仓唯一叫法，写入时勿改名）

| 名称 | 形态 | 出现位置 |
| --- | --- | --- |
| `personaProvider` | `{ botId, getPersona: () => resolvePersonaInjection(source) }`（同步 provider，返回已解析人设 `{enabled,name,text}` 或 null；与 `contextEnhancement` 同构） | host production → runtime → bridge |
| `#persona` | bridge/runtime 私有字段，保存 provider | `weixin-bridge.mjs`、`weixin-runtime.mjs`、`qq-bridge.mjs`、`qq-runtime.mjs` |
| `capturePersona(provider)` | 共享纯函数，未启用/异常返回 `null` | bridge prompt 组装处、fast command options |
| `injectPersonaContent(content, persona)` | 共享纯函数，关闭时返回输入本身 | bridge prompt 组装处、`control-command.mjs` |
| `PERSONA_TAG` / `isPersonaBody(body)` | 共享纯函数/常量 | `src/channels/shared/injected-context.mjs` |
| `PERSONA_ENDPOINTS` / `PERSONA_RPC_CHANNEL` | `{get:'bot.persona.get',set:'bot.persona.set'}` / `'/persona'` | `src/channels/shared/persona.mjs`（唯一来源，Host/Client 共用） |
| `PERSONA_I18N` | `{ zh, en, ru }` 三个扁平词典（键=中文源串） | `plugin-src/client/persona-i18n.js` |
| `personaRpcCall` | `(endpoint, payload, signal) => …` | `plugin-src/client/index.js` → 渠道设置页 prop |
| `savePersona(account, persona)` | 渠道设置页保存助手（**不要**复用 `saveBotSetting`/`botAction`：那两者把渠道 `set*` 的整份状态快照写回，而 `bot.persona.set` 返回 `{ persona }`） | `weixin/index.js`、`qq/index.js` |
| `onPersonaSave` | `(account, persona) => Promise<void>` | 渠道设置页 `AccountCard`/`AccountList` |
| `personaView(snapshot)` | 给 `status`/`deleteBot` 返回值逐 bot 补 `persona` 字段 | 微信/QQ `production.mjs` 的 controller Proxy |
| `bots[].persona` | 渠道状态快照上的只读人设配置 | host `production.mjs` 装饰 + client `api.js` 归一化 |
| `persona`（bot 记录字段） | 归一化后的人设对象（四字段） | client `normalizeBot`、UI `PersonaEditor` prop |
