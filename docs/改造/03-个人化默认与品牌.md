- 管理 RPC 路由：`/dsh-im`、`/dsh-im-channels`、`/dsh-im-delivery`、`/dsh-im-settings`、`/persona` 等；
- 数据目录与文件名：`<DSH_HOME>/integrations/dsh-im/`、`delivery-sync-settings.json`、`personas.json`、`persona-library.json`；
- 来源/上下文标识：`plugin:dsh-im`、`dsh-im:source-guidance`、`dsh-im:group-history`、`dsh-im:persona` 等 DSH 插件来源串与日志标签；
- 服务名 `dshImClient` / `dshIm` 与 CSS 前缀 `dim-`。

这样旧数据目录可直接复用，且不影响仓库内部一致性；彻底改名列入 `docs/改造方案.md` 的后续可选项。

## 3. 移除「检查并安装更新」

上游更新面板会访问 npm 上的 `@xmanrui/dsh-im`，在个人版里点「更新」会用上游包覆盖个人版，因此整体移除：

| 类别 | 文件/改动 |
| --- | --- |
| Host | 删除 `plugin-src/host/update-rpc.mjs`、`update-runtime.mjs`、`update-service.mjs`；`host/index.mjs` 移除 import、`startUpdate` 变量与安装调用 |
| Client | 删除 `plugin-src/client/update-panel.js`；`client/index.js` 移除 `UpdatePanel`、`UPDATE_RPC_CHANNEL`、`updateRpcCall`、`reportUpdateStatus` 与 `runningVersion` 状态（版本号直接取 `IM_PLUGIN_VERSION`） |
| 测试 | 删除 `test/update-rpc.test.mjs`、`update-runtime.test.mjs`、`update-service.test.mjs`、`update-ui.test.mjs`；测试收尾任务清理其他测试中的残留桩 |
| 脚本 | `scripts/verify-package.mjs` 移除更新文件期望并改为断言人设/品牌；`scripts/verify-lan-management.mjs` 移除 update 端点保护检查，profile patch id 改 `dsh-im-persona` |
| 文档 | 删除 `docs/检查与安装更新.md`、`docs/checking-and-installing-updates.md`；README 改为「git pull + npm install + npm run build + 重启」升级方式 |
