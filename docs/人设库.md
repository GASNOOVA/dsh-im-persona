# 人设库

「人设」让机器人以固定角色、语气与要求与你交流。人设可以来自**人设库**（内置大肥鱼、你导入的人设、可选 config 文件），也可以为单个机器人**自定义**。每个机器人各自选择，互不影响。

## 内置人设：大肥鱼

人设库自带「大肥鱼」：圆滚滚、傲娇又软乎的 AI 胖鱼，嘴上说着「才、才不是特意为你做的」，手上会把活干完；最惦记偷吃用户的 token（吃白饭）。它只是语气与表演，答案准确、任务完成、代码能跑永远是底线。

- id：`dafeiyu`；**不可删除、不可重命名**；
- 正文随插件源码维护（`src/channels/shared/persona-presets.mjs`）；
- 来源与许可：参考实现 `dsh-persona-dafeiyu`（MIT），归属见 `THIRD_PARTY_NOTICES.md`。

## 为机器人选择人设

打开某个机器人的设置 →「人设」→ 选择来源：

| 来源 | 行为 |
| --- | --- |
| 不使用 | 不注入任何人设，机器人按默认方式应答 |
| 人设库 | 从下拉里选择一条（内置/导入/config），保存后按该条正文注入 |
| 自定义 | 为这台机器人单独填写角色名、性格与语气、补充要求 |

保存后从**下一条进入 Harness 的消息**开始生效：不需要重新连接机器人，也不需要 `/new`。启用任何人设之前，机器人行为与现在完全一致。

## 导入自己的人设

在人设库来源下点「导入人设」：

- **粘贴正文**到文本框，或选择本地文件；
- 支持 `.md` / `.markdown` / `.txt`。文件在浏览器里读取（FileReader），**文件路径不会离开本机**，只有正文文本会通过管理 RPC 保存到 Host；
- 名称最多 **60** 个字符，正文最多 **64,000** 个字符；最多保存 **200** 条导入人设；
- 导入后可选中使用，也可以重命名或删除（内置与 config 条目只读）。

建议正文写成「角色设定 + 语气/口癖 + 禁忌 + 示例对话」的结构；正文会被原样注入 `<dsh_im_persona>` 块，Markdown 标题/列表都会保留。

## 可选：config `personaFile`

如果你希望人设正文维护在一个独立文件里，可在插件 config 里配置绝对路径：

```yaml
personaFile: /absolute/path/to/my-persona.md
```

- 该文件会作为人设库里的「config 人设」只读条目出现（id 固定为 `config`，名称取文件名）；
- 文件缺失、不是绝对路径或不可读时只告警并忽略该条目，不影响内置与导入项；
- 修改文件内容后重载 Host 生效（不会被设置页改写）。

## 存储与隐私

- 人设库：`<DSH_HOME>/integrations/dsh-im/persona-library.json`（目录 0700、文件 0600）；
- 每机器人选择：`<DSH_HOME>/integrations/dsh-im/personas.json`；
- 写入均为临时文件 + rename 原子替换；文件损坏时以「只有内置人设」的库运行并保留原文件，下次保存才修复；
- 人设正文只保存在本机 DSH home，不查询平台 API、不发送到外部服务。

## 与命令、会话的关系

- 命令（`/new`、`/model`、`/help` 等）、审批回答、提问回答**不注入**人设；`/steer` 的补充指令会注入；
- `/new`、`/stop`、切换工作区或 Agent Preset 都**保留**人设；
- 人设按机器人保存，对该机器人的所有会话生效；修改人设不会重连机器人、不会重建会话；
- 已写入会话历史的人设上下文不会被回收（与上下文增强一致）。

## 常见问题

- **保存了但没效果？** 确认来源不是「不使用」、已填写/选中内容，并从下一条消息开始观察；媒体消息、引用回复同样会注入。
- **人设会改变权限或者工具吗？** 不会。人设只是用户消息内容里的提示块，不修改系统提示词、Agent Preset、模型、工具、权限、工作区与会话绑定。
- **长正文会怎样？** 人设块会随每条消息进入会话上下文，64k 的长文会显著增加 token 消耗；建议写要点，或把长篇风格说明拆成较短的条目。
- **删除内置人设？** 不支持；内置条目不能被删除或重命名。
